# CPR Community — النسخة التأسيسية

## محتوى النسخة
- واجهة عربية داكنة كبداية.
- تنقل سفلي: الرئيسية، ملف اللاعب، المجتمع، الإدارة.
- ملفات Flutter مفصولة حسب الوظيفة.
- GitHub Actions لبناء APK من المستودع.

## ملاحظات مهمة
- البيانات المعروضة كعناصر نائبة وليست بيانات حقيقية من السيرفر.
- لا يوجد تسجيل دخول أو اتصال بماينكرافت في هذه المرحلة.
- صفحة الإدارة لا تنفذ أوامر ولا تطبق صلاحيات بعد؛ لا تضف أسراراً أو مفاتيح API داخل التطبيق.
- لم يتم تشغيل Flutter build داخل بيئة الإنشاء هذه؛ نجاح البناء يجب التحقق منه عبر GitHub Actions.

## البناء من الهاتف
1. أنشئ مستودع GitHub جديداً وارفع محتويات هذا المجلد إليه.
2. تأكد أن الفرع اسمه `main`.
3. افتح تبويب **Actions** في المستودع.
4. شغّل **Build CPR Community APK** أو ادفع commit جديداً.
5. افتح نتيجة التشغيل الناجح ونزّل artifact باسم `cpr-community-apk`.

## المرحلة التالية
تحديد اسم السيرفر النهائي، ثم إعداد تسجيل الدخول والأدوار من جهة الخادم قبل ربط بيانات اللاعبين.
